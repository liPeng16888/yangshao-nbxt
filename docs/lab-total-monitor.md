# 合量监测

后台入口：`/admin/lab-total-monitor`。每个前台主账号分别保存监测规则；前台子账号继承其数据主账号的规则。超级管理员与获授权的子管理员可以配置，服务端按授权账号范围校验每次读取与保存。前台接口只读。

## 判断规则

- 可添加、编辑、移除和启用/停用多条规则，保存整个账号的配置后生效。
- 每条规则包含名称、铁计算值下限/上限、合量正常下限/上限、启用状态。上下限均包含端点。
- 铁的输入字段为 `ironRaw`，硅为 `siliconRaw`，铝为 `aluminumRaw`。三项都必须是有限数值，并且铁、硅、铝、合量计算结果也都是有限数值。0 是有效输入；缺少任何一项时不判异常。
- 比较 `results.iron` 和 `results.total`，不比较原始读数，不改变原有公式、调整数或参数快照。
- 例如铁在 `[5, 10]` 时，合量在 `[80.5, 82.5]` 为正常；低于 80.5 或高于 82.5 为异常。
- 已配置并启用规则，但铁计算值没有匹配任何区间时，也判为异常。
- 未配置规则或所有规则均停用时，监测关闭。
- 启用的铁区间不允许重叠，包含相同端点也算重叠。如第二条从 10.0001 开始，可与 `[5, 10]` 并存。
- 使用完整计算精度（现有计算结果四位小数）比较；表格仍沿用两位小数显示，异常说明显示用于判断的具体计算值。

## 前台提示与生成

桌面合量格显示浅红背景和异常说明；手机合量卡同样变色并显示“合量异常”。完成样品的访问保护仍生效，不通过异常提示泄露隐藏数据。

生成短信或报告的实际预览前刷新规则，只检查本次选择的样品。存在异常时列出样品、铁计算值、合量值和正常范围。选择“返回检查”或关闭提示则停止生成；选择“仍然生成短信/报告”才继续。规则加载失败时停止生成并提示重试。正常和三项未齐全的样品不触发该确认。

生成数据采用点击时的样品快照，保证确认的数值与生成的数值一致；账号、日期上下文或规则版本变更会使尚未完成的确认失效。前台通过实时事件、回到窗口和定时刷新接收后台更新；不会覆盖正在录入的样品数据。

## 批量添加到其他账号

先保存来源账号的配置，再点击“批量添加到其他账号”。可勾选部分或全部已保存规则，并选择一个或多个其他前台主账号，单次最多 100 个目标账号。

批量操作采用追加方式，保留目标账号原规则。相同铁/合量范围与启用状态的指标会去重，目标账号原名称和标识保留。新指标使用目标账号独立标识，后续编辑互不影响。

追加后任意启用铁区间重叠，或规则总数超过 100 条时，整个目标账号跳过，不会写入其中一部分。其他账号继续处理，页面逐一列出已添加、无需添加、已跳过、版本冲突或失败及其原因。

服务端在任何写入前校验来源与所有目标的授权范围；请求包含未授权账号时，整批拒绝。来源版本过期或选择的规则已删除时同样拒绝。目标保存仍使用版本条件，防止覆盖其他管理员的并发修改。成功追加后沿用现有实时通知。

## 存储与接口

`LabTotalMonitorSetting` 按 `frontendUserId` 唯一保存 JSON 规则，包含版本、修改人和时间。首次创建和更新均检测版本冲突，阻止管理员之间互相覆盖。新表迁移：`server/prisma/migrations/20261010000000_add_lab_total_monitor/migration.sql`。

| 接口 | 用途 |
| --- | --- |
| `GET /api/lab-total-monitor` | 前台读取当前身份数据主账号的规则 |
| `GET /api/admin/lab-total-monitor/:frontendUserId` | 后台读取授权账号的规则 |
| `PUT /api/admin/lab-total-monitor/:frontendUserId` | 后台保存 `{ rules, baseVersion }` |
| `POST /api/admin/lab-total-monitor/bulk` | 批量追加 `{ sourceFrontendUserId, sourceVersion, ruleIds, frontendUserIds }`，返回逐账号结果 |

正式环境按项目既有流程执行 Prisma migrations，并构建/启动 Nest 服务；本次没有连接或迁移正式数据库。

## 本地模拟预览

当前 5173/5174 页面使用项目的模拟数据模式。开发专用 Vite 中间件让两个端口读取同一份本机临时规则文件；模拟预览不写正式数据库。后台选择“模拟前台管理员（admin）”即可对应当前前台模拟账号 `u-admin`；其他模拟账号仍各自独立。中间件仅接受本机连接、只允许后台端口写入，不加入生产浏览器构建或 preview server。

本次为模拟账号保存了两条示例规则：铁 `[5, 10]` / 合量 `[80.5, 82.5]`，铁 `[10.0001, 20]` / 合量 `[83, 86]`。用于测试的前台样品输入已恢复为空。
