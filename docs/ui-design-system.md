# 仰韶化验室界面规范

前台和后台从各自 main.ts 引入 `shared/styles/ui.scss`。基础颜色和 Element Plus 变量集中在 `_tokens.scss`，图表配置集中在 `shared/chartTheme.ts`。

| 内容 | 规范 |
| --- | --- |
| 背景 | 雾白 `#f5f6f7`，工作区域白色，浅层表面 `#f7f8f9` |
| 文字 | 正文 `#29343d`，辅助 `#4d5963`，次要 `#66737d` |
| 强调 | 灰蓝 `#5e7687`，悬停 `#4a6273`，选中底色 `#edf2f5` |
| 语义 | 灰绿成功、土黄警告、陶土红错误；保留文字和图标 |
| 边线 | 普通 `#dce2e6`，轻分隔 `#e9edef`，样品网格 `#cdd6dc` |
| 圆角 | 控件 6px，面板 8px，浮层 10px；沿用需要紧凑操作的局部尺寸 |
| 字体 | Inter／PingFang SC／Microsoft YaHei／系统字体，正文主要为 14–16px |
| 图标 | 现有 Element Plus Icons；菜单约 18–20px，按钮约 16px |
| 数字 | 金额、数量使用等宽数字与右对齐，保留精度和单位；描述性内容左对齐 |
| 按钮 | 主要动作填充，普通动作描边，辅助动作文字；危险动作保留警示语义 |
| 焦点 | 灰蓝边线与轻焦点圈；样品格有单独样式以避免局部样式覆盖 |
| 图表 | 灰蓝收入、陶土支出、低饱和分类色、轻网格线、明确图例与单位 |

布局先用对齐、间距、标题和分隔线分组，避免重复卡片和大阴影。桌面样品表保持多行分组与录入密度；移动端保留现有折叠、标签、筛选和保存方式。表格、日历的滚动留在所属区域内。

新增页面继续复用以上变量。少量既有业务颜色（如已完成样品的淡桃色）以及正式报告／导出版式按原有约定保留。

数据计算页的样品录入表按用户反馈统一居中显示输入值、计算结果与备注；其他财务列表仍按金额与数量右对齐的规范呈现。

2026-10-10 用户选定第一款「陶印字标」。前后台统一使用 `shared/BrandLogo.vue` 和透明图片 `shared/assets/yangshao-logo-seal.png`，桌面侧栏沿用 40px 图标槽位，移动端顶部／抽屉为 32px，登录标题为 48px。图片本身包含陶土色底形，不再叠加旧文字标记的背景或边框。后续使用方式与素材生成提示见 `docs/brand-logo-2026-10-10.md`。
