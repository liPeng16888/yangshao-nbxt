# 仰韶桌面软件 1.0.1 基础能力整改 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把报告相关配置改为主账号与子账号共享的服务器数据，并补齐桌面端剪贴板、右键、加载、查找、缩放和 1.0.1 可追溯安装包能力。

**Architecture:** NestJS 按 `CurrentUser.dataOwnerId` 保存四个分区式 JSON 配置，以 `version` 做乐观并发，以 `CurrentUser.id` 记录修改人；Vue/Pinia 以服务器为真源、按 owner 缓存并一次性迁移旧 localStorage。Electron 远程主窗口继续保持无 preload/IPC，右键使用原生 role，加载页和查找窗只加载本地可信内容，最后由同一仓库构建两个产品的 1.0.1 安装包。

**Tech Stack:** Vue 3、Pinia、Element Plus、Axios、NestJS 10、Prisma 6、PostgreSQL、Vitest、Electron 43.2.0、electron-builder 26.15.7、pnpm 11.7.0。

## Global Constraints

- 主账号与全部 `FRONTEND_SUB_USER` 只通过服务端解析的 `dataOwnerId` 共用同一套配置；请求体和路由不接受 owner ID。
- 共享分区固定为 `LAB_REPORT_TEMPLATE`、`LAB_REPORT_SMS_TEMPLATE`、`LAB_REPORT_SAMPLE_UNITS`、`LAB_ELEMENT_GROUPS`。
- 化验表未保存草稿、临时系数/标样计算、窗口位置和界面偏好继续保存在当前电脑，不上传服务器。
- 后台管理网页严格只读，不新增模板读写页面或后台写接口。
- 远程业务窗口保持 `nodeIntegration:false`、`contextIsolation:true`、`sandbox:true`、`webSecurity:true`、无 preload、无 IPC。
- Electron 固定 `43.2.0`，electron-builder 固定 `26.15.7`，桌面版本升级为 `1.0.1`。
- 只支持 Windows 10/11 x64 和 macOS 13+ Apple Silicon arm64；不签名、不公证、不自动更新。
- 当前阶段只修改本地 `codex/desktop-installers` 工作树；不推送 GitHub、不部署 VPS、不执行生产数据库迁移。
- 每个任务严格执行 RED → 确认失败原因 → 最小 GREEN → 相关回归 → 独立提交。

export async function writeTextToClipboard(text: string) {
  try {
    await navigator.clipboard.writeText(text)
    return
  } catch {
    const textarea = document.createElement('textarea')
    textarea.dataset.clipboardFallback = 'true'
    textarea.value = text
    textarea.readOnly = true
    textarea.style.position = 'fixed'
    textarea.style.opacity = '0'
    document.body.appendChild(textarea)
    try {
      textarea.select()
      textarea.setSelectionRange(0, text.length)
      if (!document.execCommand('copy')) throw new Error('复制失败')
    } finally {
      textarea.remove()
    }
  }
}

export class LoadingCoordinator {
  private generation = 0
  private timer: ReturnType<typeof setTimeout> | undefined
  private state: 'idle' | 'loading' | 'failed' | 'disposed' = 'idle'

  start(mode: LoadingMode) {
    if (this.state === 'disposed') return
    const generation = ++this.generation
    if (this.timer) clearTimeout(this.timer)
    this.state = 'loading'
    this.callbacks.show(mode)
    this.timer = setTimeout(() => {
      if (this.state === 'loading' && generation === this.generation) this.fail('timeout')
    }, 15_000)
  }
}
