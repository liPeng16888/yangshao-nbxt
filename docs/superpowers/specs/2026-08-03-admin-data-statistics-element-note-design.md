# 后台数据统计显示化验元素

## 目标

在后台管理的“数据统计”样品表中，紧跟“费用状态”新增“化验元素”列。该列展示客户前端样品已经同步到 `inputs.elementNote` 的原始文本。

## 范围

- 只修改 `admin/src/views/DataStatisticsPage.vue` 及其新增的组件测试。
- 列的固定顺序为：金额、费用状态、化验元素、铁、其余检测结果。
- 有 `elementNote` 时按原样显示；为空时显示“未选择”。
- 开启“历史数据查看”时，化验元素列显示现有的“历史”操作，并以 `elementNote` 查询单元格修改记录。

## 非范围

- 不调整客户前端填写化验元素的界面或保存方式。
- 不改变后端数据统计接口或数据库结构。
- 不把化验元素拆分为动态检测结果列。

## 验收与测试

组件测试应证明：

1. 化验元素列位于费用状态和铁之间。
2. 该列显示同步的 `elementNote` 值，缺失时显示“未选择”。
3. 开启历史查看后，点击该列历史操作时，接口参数为 `fields=elementNote`。
