# 后台财务客户筛选设计

## 目标

在后台财务报表的以下七个标签中增加客户筛选：未结款、月结款每日明细、月结款账单明细、月结客户信息收录、预存款添加记录、预存款客户、预存款每日明细。

筛选控件支持搜索、清空、单客户选择和多客户选择。选择一个客户时只显示该客户，选择多个客户时显示任一已选客户的数据；未选择时显示当前标签的全部数据。

## 交互设计

- 客户筛选位于当前标签内容区域右上方，使用 Element Plus 多选下拉框。
- 下拉选项从当前账号、月份和当前标签已经加载的数据中生成并去重。
- 每个标签独立保存自己的客户选择，切换标签后不会把另一个标签的选择错误套用过来。
- 重新查询账号或月份后，保留仍然存在的已选客户，自动移除已经不存在的选项。
- 收入账单、支出账单和删除申请不增加客户筛选。

## 数据处理

- 不修改现有后端接口和数据库结构。
- 原始接口结果继续保存在 `rows` 或 `report` 中，筛选结果通过计算属性生成，避免破坏催款、备注编辑等操作依赖的原始行对象。
- 普通财务标签从行记录的 `customer` 字段提取客户。
- 预存款客户从 `report.customerRows` 提取客户；预存款每日明细从 `report.dailyRows` 提取客户。
- 客户名称按完整显示文本进行精确匹配。组合客户名称作为一个整体选项，不拆分为多个客户。

## 组件边界

- 在 `FinanceReportsPage.vue` 内增加一个小型客户筛选栏，复用七个标签，不创建新的后端模块。
- 把客户选项生成、选择清理和行筛选提取到独立工具函数，便于单元测试并避免模板中重复判断。
- 所有表格继续复用现有列、按钮和保存函数，只替换 `:data` 的数据来源为当前标签对应的筛选结果。

## 错误与空状态

- 当前标签没有客户数据时，下拉框保持禁用或空选项，表格沿用原有空状态。
- 客户字段为空的行仍在未筛选状态下显示；一旦选择客户，空客户行不匹配任何客户。
- 接口加载失败仍由现有请求处理机制负责，本功能不吞掉错误。

## 验证

- 单元测试覆盖客户去重、单选、多选、空选择、空客户和组合客户名称。
- 页面测试覆盖七个目标标签使用筛选后的数据，并确认收入、支出、删除申请不显示客户筛选。
- 运行后台类型检查与生产构建。
- 在内置浏览器验证客户下拉框、标签切换和表格行数变化。
