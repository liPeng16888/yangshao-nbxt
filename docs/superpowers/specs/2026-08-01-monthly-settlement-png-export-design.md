# 月结款本月明细 PNG 导出设计

## 目标

在前台月结款页面增加“导出本月明细”功能。用户选择当前月份中的一个客户后，系统根据该客户每日检测元素统计生成可编辑账单草稿，用户为本次账单中的每个元素临时填写单价，系统自动计算每日元素小计、元素汇总和本月总金额，并导出为 PNG 图片。

本功能只读取当前月结款报表数据。标题、日期、元素名称、数量和单价的预览修改仅影响本次导出，不回写数据计算、月结款记录或数据库；每次重新打开导出弹窗都需要重新定价。

## 入口与操作流程

- 在“月结款每日客户明细”标题右侧、客户筛选控件左侧增加“导出本月明细”按钮。
- 历史月份和当前月份均可导出，导出月份使用页面当前选择的月份。
- 点击按钮打开独立弹窗，弹窗包含客户选择、临时单价、账单编辑和图片预览四个区域。
- 客户选择为单选，只展示当前月份存在月结款每日明细的客户，并显示完整客户信息。
- 选择客户后自动读取该客户当月全部每日元素统计；没有明细时显示明确提示并禁止导出。
- 元素单价输入区按该客户当月实际出现的元素动态生成。单价必须为不小于零、最多两位小数的数字。
- 每次关闭后重新打开弹窗，客户、单价和编辑草稿全部重置，不复用上一次导出内容。
- 点击“保存为 PNG”前校验客户、明细数量和所有有效元素单价；校验失败时保留当前编辑内容并定位提示。

## 元素统计口径

- 数据来源为现有 `MonthlySettlementReport.dailyRows`，不新增后端接口，不重新扫描样品表。
- 每个每日明细中的 `elementCounts` 作为该日期的元素数量。
- “铝、硅、铝硅比”继续使用月结款统计的归并口径：三项同时存在时只形成一个“铝硅比”项目；只选择铝或只选择硅时仍分别形成独立项目。
- 硫、碳、水分、钙、镁、白度、比重、钛、灼减等其他元素保持原有统计结果。
- 单价按元素名称应用到本月所有日期的同一元素。每日元素小计为 `数量 × 单价`，金额统一保留两位小数。
- 元素汇总数量为全部日期中该元素数量之和；元素汇总金额为该元素所有每日小计之和。
- 本月总金额为所有元素每日小计之和，不使用月结款样品原有金额字段。

## 可编辑账单草稿

弹窗根据原始日报生成独立的 `MonthlyBillDraft` 内存草稿：

- `title`：默认使用“客户显示名称 + 化验账单”，允许自由修改。
- `month`：当前页面月份，仅用于图片副标题和文件名，不回写页面筛选条件。
- `customer`：所选客户及完整展示信息。
- `entries`：按日期和元素展开的明细，字段包括日期、元素名称、数量、单价和自动计算小计。

预览编辑区允许修改：

- 账单标题。
- 每条明细的日期显示文字。
- 元素名称。
- 数量。
- 单价。

编辑数量或单价后立即重新计算该条小计、元素汇总和本月总金额。编辑元素名称只改变本次草稿中的显示与汇总分组，不修改原始 `elementCounts`。不提供新增或删除明细行，避免导出内容脱离所选客户的本月检测记录。

## PNG 版式

- 图片使用白色背景、黑色细边框和居中的账单标题，整体参考用户提供的“兴东化验账单”表格。
- 主表第一列为日期，后续按元素数量动态生成若干组 `元素 | 数量 | 价格`。
- 一张表格每行最多显示五组元素列；不足五组时只生成实际需要的列，不保留多余空列。
- 同一天包含超过五个元素时自动生成续行。该日期单元格在视觉上纵向合并覆盖全部续行，元素数据按每五项一组依次排列。
- 图片表格的“价格”显示每日元素小计，不单独显示单价；单价仅在弹窗编辑区展示和修改。
- 每日明细之后生成元素汇总区，使用相同的每行最多五组规则显示元素总数量和元素总金额。
- 最后一行显示“合计”和本月总金额，总金额使用红色强调。
- 图片宽度由当前账单每行实际元素组数决定，最多按五组生成；图片高度根据日期行、续行和汇总行数量动态增长，不截断、不压缩文字。
- Canvas 按两倍像素密度绘制，导出文件名为 `客户名称-YYYY-MM-化验账单.png`，文件名中的非法字符替换为短横线。

## 代码边界

- 月结款页面只负责打开弹窗并传入当前月份、每日明细和客户选项。
- 新建独立账单弹窗组件，负责客户选择、单价输入、草稿编辑和交互校验，避免继续扩大月结款页面文件。
- 新建纯计算工具，负责从每日明细构建草稿、按五项分组、重新计算小计及汇总。纯函数不依赖 Vue，便于覆盖边界测试。
- 新建 Canvas 导出工具，接收已经校验的草稿和布局结果，只负责测量、绘制和下载 PNG。
- 复用现有图片下载超时和失败处理思路，但不修改化验报告导出逻辑。
- 不修改 Prisma schema，不执行数据库迁移，不新增后端接口，不保存临时单价。

## 错误处理

- 未选择客户：提示“请选择需要导出的客户”。
- 客户在当前月份没有元素明细：提示“该客户本月暂无可导出的检测明细”。
- 元素单价未填写或不是有效数字：标记对应元素并禁止导出。
- 编辑后的数量小于零或不是有效数字：保留输入并提示对应日期和元素。
- Canvas 创建、绘制或下载失败：关闭导出加载状态，保留弹窗和草稿，提示“账单图片生成失败，请重试”。
- 连续点击导出时只执行一个生成任务，按钮进入加载状态，避免重复下载。

## 测试

- 选择客户后只构建该客户当前月份的每日元素明细。
- 铝、硅、铝硅比组合只生成一个铝硅比项目；单独铝或硅保持独立。
- 一至五个元素在同一行生成对应数量的元素列，不出现多余列。
- 六个及以上元素按每五项分成续行，日期只显示一个纵向合并区域。
- 单价应用到全部同名元素，数量和单价变化后小计、元素汇总及总金额正确更新并保留两位小数。
- 修改标题、日期和元素名称只改变导出草稿，不修改传入的月结款报表对象。
- 未选择客户、无明细、缺少单价和非法数量时禁止导出并显示对应提示。
- 多日期、多续行和多组汇总时 Canvas 高度正确，最后一行及总金额不会被裁切。
- PNG 文件名正确清理非法字符，导出失败或超时时能恢复按钮状态。
- 前端相关单元测试、`vue-tsc --noEmit` 和生产构建通过。

## 非目标

- 不保存客户元素单价，不提供长期价格模板。
- 不修改或重新计算月结款原始金额。
- 不回写用户在预览中修改的标题、日期、元素、数量或单价。
- 不支持一次合并多个客户到同一张账单。
- 不导出 Excel、PDF 或后台账单，本次仅实现前台单客户 PNG 导出。
