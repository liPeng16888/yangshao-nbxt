# 客户总览功能设计

## 目标

在前台“报表”和“黑名单”之间增加“客户总览”，汇总当前前台账号历史上已经检测过样品的客户数据；后台增加同名页面，允许管理员在授权范围内按单个或多个前台账号查看相同统计。

本功能直接聚合现有 `LabSheet` 和 `SampleBlock` 数据，不复制、不修改历史样品数据，也不增加统计数据表。

## 统计口径

- 仅统计客户信息非空且存在检测输入的样品，检测输入沿用后端现有 `hasLabDetectionInput` 判断。
- 多客户样品作为一个组合客户统计，例如“111、222”只生成一条客户汇总，不拆分数量和金额。
- 已保存客户优先按排序后的客户 ID 组合作为分组键，避免客户展示信息更新后被拆成不同记录。
- 没有客户 ID 的手动输入客户，按去除首尾空格后的 `customerText` 分组。
- 客户展示优先使用样品快照中的完整客户信息；如客户仍存在，则用客户表中的最新完整信息补充电话、微信、微信昵称和备注。
- 样品数量每个符合条件的 `SampleBlock` 计 1。
- 累计金额使用样品的 `price`；历史样品缺少有效金额时按 0 计，但仍计入样品数量。
- 首次检测时间和最后检测时间使用样品所属 `LabSheet.date` 的最小值和最大值。

## 后端接口

### 前台接口

`GET /api/reports/customer-overview`

只使用当前 JWT 中的 `frontendUserId`，客户端不能指定其他账号。返回：

- `customerKey`
- `customer`
- `customerDisplay`
- `sampleCount`
- `totalAmount`
- `firstDetectionDate`
- `lastDetectionDate`

### 后台接口

`GET /api/admin/customer-overview?frontendUserIds=id1,id2`

- 复用 `AdminAccessService` 校验 ROOT_ADMIN 或 SUB_ADMIN 可访问的前台账号。
- 未指定账号时统计当前管理员有权访问的全部前台账号。
- 返回字段在前台接口基础上增加 `frontendUserId` 和 `frontendUserName`。
- 不同前台账号的同名客户不合并。

前后台接口均返回未筛选的完整汇总结果，客户筛选与排序由页面完成，以避免用户每次调整排序都重新查询历史表。

## 前台页面

- 路由：`/customers-overview`。
- 侧边栏位置：报表之后、黑名单之前。
- 纳入现有访问密码保护范围。
- 顶部提供可搜索的客户多选框；选择一个即为单客户筛选，选择多个即为多客户筛选。
- 提供排序字段和升降序控件，默认按最后检测时间降序。
- 表格列：客户完整信息、样品数量、累计金额、首次检测时间、最后检测时间。
- 表格列标题支持直接排序，顶部排序控件与表格排序状态保持一致。
- 没有数据时显示“暂无客户检测数据”，请求失败时保留页面并显示明确错误提示。

## 后台页面

- 路由：`/admin/customer-overview`。
- 侧边栏增加“客户总览”。
- 顶部复用现有前台账号多选器，支持单账号和多账号筛选。
- 增加客户多选器和排序控件，交互与前台一致。
- 表格列：前台账号、客户完整信息、样品数量、累计金额、首次检测时间、最后检测时间。
- 多账号查询时按“前台账号 + 客户组合”分别显示，不跨账号合并。

## 代码边界

- 后端聚合逻辑集中在独立的客户总览服务方法中，前台和后台接口复用同一个纯聚合函数。
- 客户名称提取和完整信息格式化复用现有财务与后台数据页面的规则，避免不同页面展示不一致。
- 前台增加独立 API 类型、页面和路由；不把客户总览逻辑塞入现有报表图表 store。
- 后台增加独立页面和 API 调用，保持现有管理端页面结构。
- 不修改 Prisma schema，不运行数据库迁移。

## 测试

- 同一客户跨日期的样品正确累加数量、金额并计算首次和最后日期。
- 组合客户作为单条记录，不拆分或重复金额。
- 客户 ID 相同但展示信息更新时仍合并，并展示最新完整信息。
- 手动输入客户按规范化名称合并。
- 无客户或无检测输入的空样品不统计。
- 缺少金额的历史样品数量正常统计，金额按 0。
- 后台多账号数据不跨账号合并，子管理员不能查看未授权账号。
- 前后台客户单选、多选及各排序字段行为正确。
- 前台路由受到现有访问密码保护。

## 非目标

- 不建立可编辑的客户档案页面。
- 不修改、清洗或迁移历史样品数据。
- 不拆分组合客户的数量或金额。
- 不加入日期范围筛选；客户总览统计账号全部历史检测数据。
