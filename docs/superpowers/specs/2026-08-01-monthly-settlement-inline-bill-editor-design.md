# 月结款账单底部直接编辑设计

## 目标

简化“导出本月详细费用”弹窗：删除中间逐条编辑表，保留顶部元素单价批量定价，并允许用户直接在底部紧凑账单中修改标题、日期、元素和数量。底部价格始终由数量乘以顶部单价自动计算。

## 交互设计

- 顶部保留客户选择和各元素单价输入框。
- 删除中间标题输入框和“日期 / 元素 / 数量 / 单价 / 小计”编辑表。
- 底部账单标题改为可直接编辑的无边框输入框。
- 底部表格继续使用 `日期 | 元素 | 数量 | 价格`，每行最多五组元素。
- 日期、元素、数量在底部表格内直接编辑；价格只读，显示 `数量 × 顶部单价` 的小计。
- 超过五个元素时继续换行，日期单元格保持跨行。
- 元素汇总和总金额自动跟随底部修改重新计算。
- 弹窗关闭后仍丢弃草稿，任何编辑和单价只对本次导出有效。

## 铝硅比归并规则

- 归并发生在单个样品的元素选择解析阶段。
- 同一样品同时选择铝、硅、铝硅比时，只计一个铝硅比，不再分别累计铝和硅。
- 只选择铝、只选择硅，或只选择其中两个时，按实际选择分别统计。
- 前端模拟数据逻辑与后端现有单样品归并逻辑保持一致。

## 数据与计算

- `MonthlyBillEntry.unitPrice` 继续作为草稿中的单价来源。
- 顶部按元素定价时，更新所有相同 `sourceElementKey` 的条目。
- 底部修改日期、元素或数量时，继续通过 `updateMonthlyBillEntry` 生成新草稿并重算。
- 底部价格和 PNG 价格均使用条目 `subtotal`，不允许直接覆盖。

## 验证

- 单元测试覆盖单样品铝、硅、铝硅比三选归并。
- 组件测试确认中间编辑表被删除，底部存在可编辑标题、日期、元素、数量，价格只读。
- 验证顶部单价和底部数量修改后，小计、汇总和总金额同步变化。
- 运行相关 Vitest、`vue-tsc --noEmit`、生产构建，并通过内置浏览器检查桌面和窄屏布局。
