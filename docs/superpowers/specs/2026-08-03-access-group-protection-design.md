# 访问密码组合与已完成样品隐藏设计

## 目标

将当前“全功能共用一套访问密码”的设置替换为按当前登录账号管理的访问组合。每个组合有独立密码，并可包含多个功能；同一功能只能属于一个组合。为已完成样品增加敏感字段隐藏和受组合密码验证后查看的能力。

## 功能范围

可分配的功能固定为：

- 财务
- 报表
- 黑名单
- 历史日期查看
- 药品库存（库存、入库、出库）
- 客户总览
- 查看已完成样品的隐藏数据

未分配到任何组合的功能不需要访问密码。新版本不迁移、不自动创建旧单密码组合；原单密码配置不再参与访问判断。

## 访问组合

每个组合归属于一个前台账号，并包含：组合名称、密码、免输密码时长、找回提示词、找回答案、启用状态和功能列表。

- 创建组合时至少选择一个尚未分配的功能。
- 编辑组合时可增加未分配功能或移除已有功能。
- 功能在同一账号内唯一归属，数据库和前端均强制该约束。
- 删除组合须二次确认。删除后，组合中的功能恢复为未保护状态。
- 同一组合内的全部功能共用该组合密码与免输时长；不同组合的验证时效独立计算。

## 访问设置界面

访问设置改为组合列表页：

1. 顶部说明“按组合管理密码；一个功能只能加入一个组合”。
2. 每张组合卡片显示名称、已包含功能、免输时长与启用状态，并提供编辑、删除按钮。
3. “新建组合”和“编辑组合”使用同一弹窗，输入组合名称、密码、确认密码、找回信息、免输时长，并勾选功能。
4. 已被其他组合占用的功能显示所属组合且不可选择。
5. 删除组合、关闭已启用组合的保护均要求输入该组合当前密码确认。

## 后台客户账号信息同步

后台“账号管理 -> 客户账号”的“前端访问密码”列改为展示该客户账号的访问组合摘要，而不是旧的单密码信息。每个组合展示组合名称、启用状态、已包含功能、访问密码、免输时长、找回提示词和找回答案。

后台仅展示同步结果，不提供另一套独立编辑入口；前端账号在“访问设置”创建、编辑、删除组合后，后台刷新即可看到同一份数据。账号没有创建组合时显示“未创建访问组合”。

## 路由与验证行为

路由守卫按“页面路径 -> 功能 -> 组合”查找规则。匹配到启用组合且该组合会话已过期时，弹出该组合的访问验证；验证成功后仅解锁该组合内功能，直到该组合的免输时长到期。

历史日期访问使用“历史日期查看”功能，而非当前全局密码。药品库存的三个子页面共用“药品库存”功能。

## 已完成样品隐藏行为

标记为完成的样品保留编号、样品名称、付款客户、数据发送客户、化验元素和备注等非敏感信息。以下字段在未验证“查看已完成样品的隐藏数据”所属组合时显示为“已隐藏”：

- 所有原始检测输入和计算结果；
- 样品金额；
- 结款状态。

当该功能未归属组合时，已完成样品不隐藏这些字段。功能归属启用组合时，未验证的用户不能在页面渲染中取得上述字段；验证后重新读取当前日期样品并显示。组合验证失效后再次遮罩。

正式后端模式下，未携带对应有效组合授权的读取接口返回已完成样品的脱敏字段，不能仅依赖前端遮罩。演示模式使用当前账号本地组合设置与同样的页面可见性规则。

## 数据与接口

新增账号范围的访问组合及组合功能关联数据结构，功能类型使用固定枚举。关联表在 `(frontendUserId, feature)` 上唯一，防止重复使用功能。

替换单一访问设置接口为组合的列出、创建、更新、删除与密码验证接口。验证结果按组合保存短时授权；读取样品数据时携带该授权，以决定是否返回已完成样品敏感字段。

## 错误处理

- 功能重复分配返回明确提示并不保存。
- 创建或启用组合缺少名称、功能、密码或找回信息时不保存。
- 删除、关闭保护、修改已启用组合密码时验证当前组合密码。
- 无对应组合时不弹密码框；有组合但未启用时也不弹密码框。
- 已完成数据授权不足时保持页面可用，仅遮罩敏感字段并显示“输入访问密码后查看”。

## 验收与测试

- 一个账号可创建多个组合，组合密码互不影响。
- 任何功能无法同时出现在两个组合中。
- 财务+报表一组、历史日期+已完成数据一组时，两组分别验证且时效独立。
- 药品库存、客户总览可分配后触发各自组合验证。
- 已完成样品在未授权时仅遮罩检测数据、金额和结款状态，其他字段仍显示；授权后恢复显示。
- 移除或删除组合后，对应功能不再受保护。
- 后台客户账号列表显示与前端访问设置完全一致的组合、功能、密码、免输时长和找回信息。
- 前后端接口、迁移和本地演示模式都有覆盖测试。
